# Пояснительная записка

## Название проекта

TaskFlow

## Идея проекта

TaskFlow — это веб-приложение для управления учебными проектами и задачами. Пользователь может зарегистрироваться, создать проект, добавить задачи, указать статус и приоритет, а также прикрепить файлы к задачам.

## Актуальность

При работе над учебными проектами часто нужно распределять задачи, отслеживать прогресс и хранить материалы. TaskFlow решает эту проблему через простой веб-интерфейс.

## Использованные технологии

В проекте использованы Python, Flask, Flask-Login, Flask-WTF, SQLAlchemy, SQLite, Bootstrap, Jinja2 и REST API.

## Структура приложения

Проект разделён на несколько частей:

- data — ORM-модели и подключение базы данных;
- forms — формы регистрации, входа, проектов и задач;
- routes — обработчики страниц и API;
- templates — HTML-шаблоны;
- static — CSS и загружаемые файлы;
- docs — документация проекта.

## Модели базы данных

### User

Модель пользователя хранит имя, email, хеш пароля и дату создания аккаунта.

### Project

Модель проекта хранит название, описание, дату создания и владельца.

### Task

Модель задачи хранит название, описание, статус, приоритет, дедлайн и связь с проектом.

### Attachment

Модель файла хранит имя файла, путь к файлу и связь с задачей.

## Основные возможности

Пользователь может зарегистрироваться и войти в аккаунт. После входа он может создавать проекты и задачи. Каждая задача может иметь статус, приоритет и дедлайн. К задаче можно прикрепить файл. Также приложение предоставляет REST API для получения проектов и задач в формате JSON.

## Защита данных

Пользователь видит только свои проекты и задачи. Если пользователь попытается открыть чужой проект или задачу, приложение вернёт ошибку доступа.

## Вывод

В результате был создан рабочий учебный WEB-проект, использующий основные технологии модуля: Flask, HTML-шаблоны, Bootstrap, формы, авторизацию, ORM, базу данных, загрузку файлов и REST API.

## Возможности развития

В дальнейшем можно добавить совместную работу нескольких пользователей над одним проектом, комментарии к задачам, поиск, фильтрацию и уведомления о дедлайнах.
