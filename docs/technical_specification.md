# Техническое задание

## Название проекта

TaskFlow

## Тип проекта

Веб-приложение.

## Цель проекта

Создать веб-приложение для управления учебными проектами и задачами.

## Основные пользователи

Ученики, которые работают над проектами и хотят хранить задачи, сроки и файлы в одном месте.

## Основные функции

1. Регистрация пользователя.
2. Авторизация пользователя.
3. Создание проекта.
4. Просмотр списка проектов.
5. Редактирование проекта.
6. Удаление проекта.
7. Создание задачи внутри проекта.
8. Просмотр задач проекта.
9. Редактирование задачи.
10. Удаление задачи.
11. Изменение статуса задачи.
12. Загрузка файла к задаче.
13. Получение данных через REST API.

## Требования к данным

В базе данных должны храниться пользователи, проекты, задачи и прикреплённые файлы.

## Требования к интерфейсу

Интерфейс должен быть оформлен с использованием Bootstrap. Пользователь должен иметь возможность выполнять основные действия через HTML-страницы.

## Требования к API

API должно возвращать данные в формате JSON.

## Требования к запуску

Проект должен запускаться после установки зависимостей из requirements.txt.
