# План презентации

## Слайд 1. Титульный

TaskFlow

Веб-приложение для управления учебными проектами и задачами.

Авторы: ФИО участников.

## Слайд 2. Идея проекта

TaskFlow помогает создавать проекты, добавлять задачи, отслеживать их выполнение и хранить файлы.

## Слайд 3. Проблема

При работе над проектом задачи часто теряются, файлы лежат в разных местах, а статус выполнения непонятен.

## Слайд 4. Основные возможности

- регистрация и вход;
- создание проектов;
- создание задач;
- статусы и приоритеты;
- загрузка файлов;
- REST API.

## Слайд 5. Использованные технологии

- Python;
- Flask;
- SQLAlchemy;
- SQLite;
- Flask-Login;
- Flask-WTF;
- Bootstrap;
- REST API;
- Git.

## Слайд 6. Структура проекта

- data;
- forms;
- routes;
- templates;
- static;
- docs.

## Слайд 7. База данных

В проекте есть четыре основные модели:

- User;
- Project;
- Task;
- Attachment.

## Слайд 8. Демонстрация

Показать регистрацию, вход, создание проекта, создание задачи, загрузку файла и API.

## Слайд 9. Распределение работы

Участник 1 занимался backend и базой данных.

Участник 2 занимался frontend и файлами.

Участник 3 занимался API, документацией и финальной сборкой.

## Слайд 10. Выводы

Проект получился рабочим и использует основные технологии WEB-модуля. В дальнейшем можно добавить совместные проекты, комментарии и уведомления.
